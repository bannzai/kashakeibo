# アカウントの削除について

アプリ「カシャケイボ」（デベロッパー: bannzai）のアカウント削除手順と、削除されるデータについて説明します。

## アプリからアカウントを削除する手順

1. アプリを起動する
2. 「設定」を開く
3. 画面下部の「アカウントを削除する」をタップする
4. 確認ダイアログで「削除する」をタップする

削除を実行すると、その場でアカウントが削除されます。再度アプリを開くと、サインインしていない状態から始まります。

サインインしてから時間が経っている場合、セキュリティのため再ログインを求められることがあります。その場合は画面の案内に従って再度サインインしてから、もう一度削除操作を行ってください。

## 削除されるデータ

アカウント削除の操作により、次のデータが削除されます。

- アカウント情報（Firebase Authentication のユーザーアカウント）
- サインインに使用した認証情報（Apple ID / Google アカウントとの連携）
- 登録した明細データ（金額、日付、店名、カテゴリ等）
- 撮影・アップロードした画像（レシート写真、スクリーンショット）

これらは削除操作と同時に削除され、復元できません。保持期間の定めはなく、削除後にデータが残ることはありません。

## 削除後も保持されるデータ

有料サービスの購入履歴は、Apple / Google の決済プラットフォームおよび購入管理サービス（RevenueCat）の定めに従って取り扱われ、提供者が任意に削除できません。それ以外に提供者が保持するデータはありません。

アプリを操作できない状態でアカウントの削除を希望される場合は、下記の連絡先までご連絡ください。ご連絡から 30 日以内に対応します。
