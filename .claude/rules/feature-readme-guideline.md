# Feature README ガイドライン

各機能 (Feature) ディレクトリには `lib/features/{feature_name}/README.md` を作成し、コードを読まなくても機能の仕様を把握できる入口にする。記載内容:

- **概要**: 機能の説明
- **画面**: 画面名・表示条件・操作内容
- **フロー**: ユーザーの操作フロー（ステップバイステップ）
- **データ形式**: 関連するデータの形式や制約（該当する場合）
- **有効期限・制約**: 期限や制限事項（該当する場合）
