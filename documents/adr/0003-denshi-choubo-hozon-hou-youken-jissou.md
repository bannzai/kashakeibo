# 0003. 電子帳簿保存法のスキャナ保存要件の基盤は実装し、「電帳法対応」の訴求は別判断とする

- ステータス: 採用 ([ADR 0002](0002-denshi-choubo-hozon-hou-out-of-scope.md) を Supersede する)
- 日付: 2026-08-23
- 決定の経緯: https://github.com/bannzai/kashakeibo/issues/73 (方針変更の起票。チェック結果の記録は issue #65 / ADR 0002)

## 背景 (Context)

[ADR 0002](0002-denshi-choubo-hozon-hou-out-of-scope.md) で、カシャケイボは電子帳簿保存法の適用対象外であり「電帳法対応」を謳わないと整理し、仮に対応を謳う場合の未充足要件として「訂正削除履歴・タイムスタンプ・画質担保・検索要件」を記録した。

その後の方針変更 (issue #73) で、これらの技術要件は**いずれにしても実装する**ことにした。将来の事業者向け訴求の選択肢を確保し、家計簿としても監査性 (操作履歴の確認) と検索性の向上に直結するためである。

## 決定 (Decision)

**スキャナ保存要件に対応する技術基盤を実装する。ただし「電帳法対応」をストア文言・アプリ内コピーで訴求するかどうかは、引き続き本 ADR とは別の判断とする (本 ADR の時点では訴求しない)。**

実装する要件と方式:

1. **訂正削除履歴**: 明細 (Firestore の transaction) の作成・訂正・削除と、画像 (R2) の削除を、`users/{userID}/auditLogs` サブコレクションに監査ログとして記録する。「いつ」はサーバー時刻 (`serverCreatedDateTime`) で記録し、アプリの操作履歴画面から確認できる。履歴は本人のデータとして `users/{userID}` 配下に閉じ、アカウント削除時は履歴も含めて全削除する (docs/AccountDeletion.md の「削除操作と同時に削除される」方針を維持)
2. **タイムスタンプ**: スキャナ保存の要件は「タイムスタンプ付与」または「訂正・削除の履歴が残るシステム」のいずれかで満たせるため、1 の履歴方式を正とする。認定タイムスタンプ (TSA) の外部サービス契約・連携はスコープ外とし、必要になったら別 issue で判断する。画像アップロード時刻は Worker のサーバー時刻 (`uploadedAt`)、明細登録時刻は Firestore の `FieldValue.serverTimestamp()` で記録し、クライアント申告の時刻に依存しない
3. **画質担保**: 画像アップロード時に Worker 側でバイナリヘッダーから実寸 (幅・高さ px) を取得し、判定結果を R2 の customMetadata に記録する。解像度 200dpi 相当以上の判定は、レシート実寸が不明なため、国税庁の一問一答 (スキャナ保存関係) がスマートフォン読取りに示す「A4 サイズを 200dpi で読み取った場合の約387万画素以上」を近似基準として採用する。RGB 256階調以上は画像形式のヘッダー情報 (ビット深度・カラータイプ) で判定する。基準未満でも保存は拒否せず (家計簿用途を阻害しない)、判定結果を後から参照できることを受け入れ条件とする
4. **検索要件**: 取引年月日 (範囲指定)・取引金額 (範囲指定)・取引先 (店名) で明細を検索できる UI と、必要な Firestore 複合インデックスを実装する

## 影響 (Consequences)

- ADR 0002 の「対応は行わない (要件を実装しない)」という整理は本 ADR で置き換える。一方、**「電帳法対応」を想起させる訴求をしないという制約は本 ADR でも維持する**。デザインハンドオフの確定申告関連文言の扱い (ADR 0002 の「影響」に列挙した `design_handoff_kashakeibo` 配下の各文言を集計データの書き出しの範囲の表現に改める) も同様に維持する
- 監査ログは Firestore Rules を「本人認証 + 所有判定のみ」に保つ方針 (`.claude/rules/firestore-rules-simplicity.md`) の範囲内で保存するため、アプリ UI からは編集・削除できないが、本人がクライアント SDK を直接使えば技術的には書き換えられる。法的要件としての完全な訂正削除履歴 (改ざん防止) を保証するにはサーバー側での強制が必要であり、「電帳法対応」を実際に訴求する判断をする際に、本 ADR を Supersede する ADR で再評価する
- 画像実体の物理削除をやめて保持し続ける変更 (法的な保存期間の担保) はスコープ外のままとし、ユーザーが画像をいつでも削除できるデータ設計と docs/ のプライバシー方針を変えない
- 個人事業主ユーザーが自身の保存義務のために本アプリを使うことは引き続き想定・保証せず、原本の保存はユーザーの責任範囲とする
