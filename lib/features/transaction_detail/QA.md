## 1. 表示

- [ ] **詳細表示**: 月次一覧の明細行をタップすると詳細画面が開き、金額 (収入はセージ色)・店名・日付・カテゴリ (計算対象外なら注記) と、情報カードに出所チップ (レシート/スクショ/手動 + 自動取込/手調整) が表示される
  - 自動化: manual (Maestro 未導入のため agent のシミュレータ操作で確認する)
  - 出所チップは「手動」と「スクショ + 自動取込」を確認した。「レシート」(カメラ撮影) と「手調整」は該当する明細を作っていないため未確認
- [ ] **元画像の表示と拡大**: スクショ取込した明細の詳細に元画像カードと注記「元画像はいつでも確認できます」が表示され、「拡大」でピンチ操作できる全画面表示が開く
  - 自動化: manual (Maestro 未導入のため agent のシミュレータ操作で確認する)
  - ピンチ操作自体は mobilecli にマルチタッチのジェスチャコマンドが無いため未実行 (全画面表示が開くところまで確認)
- [x] **画像なしのプレースホルダー**: 手動入力の明細では元画像カードの位置に「手動入力のため元画像なし」のプレースホルダーが表示される
  - 自動化: manual (Maestro 未導入のため agent のシミュレータ操作で確認する)

## 2. 操作

- [x] **計算対象外スイッチ**: 「計算対象から除外」を ON にすると即時保存され、本画面の注記と月次一覧の合計・カテゴリ内訳から除外される。OFF に戻すと集計に復帰する
  - 自動化: manual (Maestro 未導入のため agent のシミュレータ操作で確認する)
- [x] **画像だけを削除**: 「画像だけを削除」→ 確認ダイアログ → 実行で元画像が消えてプレースホルダー (元画像なし) になり、明細自体は一覧に残る
  - 自動化: manual (削除は元に戻せないため、専用に取り込んだ明細で確認する)
- [x] **明細の削除**: 「明細を削除」→ 確認ダイアログ → 実行で月次一覧へ戻り、明細が一覧から消えて集計が減る
  - 自動化: manual (削除は元に戻せないため、専用に登録した明細で確認する)
- [ ] **削除済み明細の表示**: 開いている明細が別クライアントから削除されると「この明細は削除されました」が表示される
  - 自動化: todo (別クライアントから kashakeibo-dev へ書き込む手順が未整備。monthly QA.md「別クライアントからの書き込みの自動反映」と同じ課題)
