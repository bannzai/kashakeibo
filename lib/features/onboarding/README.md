# onboarding（オンボーディング）

## 概要

初回起動時に、家計管理の悩みと記録対象を質問し、回答に合わせた利用プランを提示してから既存のペイウォールへ接続する課金転換型オンボーディング。

## 画面

- `OnboardingResolver`: 端末内の完了状態を読み込み、未完了の場合だけオンボーディングを表示する
- `OnboardingPage`: 進捗、質問、出典付き調査、プラン生成演出、回答を反映した結果を表示する
- 日本語・韓国語・中国語は本質的な質問に絞った7画面、英語は価値説明・利用頻度・コミットメントを加えた10画面を表示する

## フロー

1. 価値宣言を表示する
2. 家計管理で困っていることを質問する
3. 記録したい明細の種類を質問する
4. 家計簿で達成したい目標を質問する
5. 出典付きの節約効果調査を表示する
6. 回答を反映するプラン生成演出を表示する
7. 回答に合わせた利用プランを提示する
8. 完了状態を保存し、既存のペイウォールを開く
9. ペイウォールを閉じるか購入すると月次画面を表示する

英語の長尺ファネルでは、価値説明、現在の記録頻度、コミットメントを追加する。

## データ形式

- 完了状態は `SharedPreferencesAsync` の `onboarding_completed_v1` に保存する
- 質問回答は結果画面と Analytics にだけ使い、個人データとして永続化しない
- Firebase Analytics の自動収集イベント `first_open` に加えて、開始、各ステップ表示、回答、完了、1画面目のシステム戻るで閉じた操作を記録する
- ペイウォールの表示・閉じる・購入は `features/paywall` のイベントを使用する

## 制約

- 完了状態の保存に失敗した場合はペイウォールを開かず、エラーをそのまま表示して再試行できる
- トライアル商品構成と価格はストア・RevenueCat を正とし、オンボーディングには固定値を持たせない
