# monthly (月次一覧)

## 概要

当月の明細一覧と月次集計 (支出・収入・残り・カテゴリ内訳) を表示するホーム画面。
デザインは design_handoff_kashakeibo/README.md (ホームの月切替ヘッダー・収支サマリー、
レポートのカテゴリ横棒、明細タブの日付グループ行) に合わせる。
集計はサマリードキュメントを持たず、購読中の明細からクライアント集計する
(`.claude/rules/firestore-aggregation-rules.md`)。
本 README で挙げる色 (neutral-600・セージ等) は `context.appColors` (lib/style/app_theme.dart) 経由で参照し、ライト / ダークで切り替わる。

## 画面

- `MonthlyPage`: アプリのホーム画面。サインイン完了後 (`SignInResolver`) に表示される
  - 月切替ヘッダー: 左右の円形ゴーストボタンと中央の月ラベル (+ 英語表記の副題)
  - 設定導線: 月切替ヘッダー上段の設定アイコンから設定画面を開く
  - 収支サマリーカード (radius 28): 支出を主表示 (¥ 記号は小さく neutral-600)、右に収入・残り (残りはセージ)
  - 重複候補バナー: 表示月と隣接月の支出から金額・取引日 (前後3日以内)・正規化した店名が一致または包含関係にある候補を件数表示し、確認シートを開く
  - 重複確認シート: 2件の明細を比較し、残す明細を選んで「1件にまとめる」か、「別々の支出として残す」を選ぶ
  - カテゴリ内訳: 支出のカテゴリ別合計を金額の大きい順の横棒で表示 (支出が無い月は非表示)
  - 明細リスト: 日付見出しでグループ化した取引日時の降順。サブ行はカテゴリ · 出所 (レシート/スクショ/手動) · 出所記録 (自動取込/手調整。撮影・取込の明細のみ)。計算対象外の明細は opacity 0.45 + 「計算対象外」注記。金額に赤は使わない (トークンに赤が無い)。行のタップで明細詳細 (`features/transaction_detail`) を開く
  - 記録するボタン (FAB): 「記録する」シート (`features/capture` の `AddRecordSheet`) を開き、カメラで撮影 / 写真・スクショから選ぶ (どちらも AI 解析 → 確認 → 登録フロー) / 手動入力 (`ManualEntrySheet`) の 3 経路から選ぶ
  - 共有 Extension からの取り込み (`features/share_import`): 画面の表示開始時と foreground 復帰時に共有された画像を取り出し、同じ確認 → 登録フローを順に開く
  - DEBUG ビルドのみ月ラベルの長押しでデバッグメニュー (`features/debug`) を開く

## フロー

1. 起動すると当月の明細を snapshot listener で購読する (リアルタイム反映・オフラインキャッシュ対応)
2. 前月・次月ボタンで表示月を切り替えると、その月のクエリを購読し直す
3. 明細の追加・変更は listener 経由で自動的に一覧と集計へ反映される
4. 取込フロー (カメラ・写真とスクショ・共有 Extension) と手動入力で登録した明細も同じ listener 経由で一覧と集計へ即時反映される。取込フローの登録完了時は「カシャッと記録!」トーストを表示する
5. 設定アイコンをタップすると、法務ドキュメントへの導線を持つ設定画面へ遷移する
6. 重複候補をマージすると片方を残してもう片方を削除する。元画像は残す側に無ければ削除側から引き継ぎ、両方にあれば削除側の画像を R2 から消す。「別々の支出として残す」と相互の明細 ID を記録し、同じ組み合わせを再提示しない
7. マージと別物判定は Firestore トランザクションで行い、複数端末から同時操作されても両方の明細が消えたり判断が上書きされたりしない
8. 明細行をタップすると明細詳細へ遷移し、元画像の確認・計算対象からの除外・削除ができる。詳細での変更は listener 経由で一覧と集計へ反映される

## データ形式

- 明細: `/users/{userID}/transactions/{id}` の `Transaction` (lib/entity/transaction.dart)
- 月次クエリ: `yearMonth == "yyyy-MM"` + `transactionDate` 降順
  (複合インデックス: firebase/firestore.indexes.json)
- 計算対象外 (`excludedFromAggregation: true`) の明細は一覧に表示するが集計に含めない
- 別物として確定した組み合わせは、各明細の `confirmedDistinctTransactionIDs` に相手の明細 ID を保存する
