# manual_entry (手動明細入力)

## 概要

スクリーンショットやレシート画像がない現金支出・収入を、明細として直接登録する。
手動登録はスキャン無料枠を消費しない。

## 画面

- `ManualEntrySheet`: 月次一覧の「手動で入力」ボタンから開くボトムシート
  - 金額、店名・メモ、収支種別、カテゴリ、日付を入力する
  - 日付の初期値は今日
  - 収支種別を変更すると、選択可能なカテゴリも切り替わる

## フロー

1. 月次一覧で「手動で入力」をタップする
2. 必須項目を入力して「登録する」をタップする
3. `AddTransaction` が出所 `manual` の明細を Firestore に保存する
4. 月次一覧の snapshot listener が登録結果を受け取り、一覧と集計を更新する

## データ形式

- 保存先: `/users/{userID}/transactions/{id}`
- Entity: `Transaction`
- 出所: `TransactionSource.manual`

## 制約

- 金額は 1 円以上の整数
- 支出カテゴリは食費・外食・日用品・交通・サブスク・その他
- 収入カテゴリは給与・その他
