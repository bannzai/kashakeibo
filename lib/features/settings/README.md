# 設定

## 概要

アプリの設定と法務ドキュメントへの導線を提供する機能です。

## 画面

- 設定画面: 月次一覧の設定アイコンから表示します。
- 利用規約、プライバシーポリシー、特定商取引法に基づく表示をタップすると、端末の既定ブラウザで GitHub Pages の該当ページを開きます。
- 英語環境ではプライバシーポリシーの英語版を開きます。

## フロー

1. 月次一覧の設定アイコンをタップする。
2. 表示する法務ドキュメントをタップする。
3. 端末の既定ブラウザで内容を確認する。

## データ形式

Firestore などの永続データは使用しません。法務ドキュメントの公開先は `https://bannzai.github.io/kashakeibo/` です。

## 有効期限・制約

外部ブラウザを開けなかった場合は、起動処理が返したエラーを画面下部に表示します。
