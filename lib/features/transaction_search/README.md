# transaction_search (明細検索)

## 概要

取引年月日 (範囲)・取引金額 (範囲)・取引先 (店名) で明細を検索する (issue #73 の検索要件)。
月次一覧が当月に閉じているのに対し、こちらは月をまたいで明細を探すための画面。

## 画面

- `TransactionSearchPage`: 月次一覧の右上の検索アイコンから表示する
  - 取引年月日: 開始日・終了日を日付ピッカーで選ぶ (未選択は「指定なし」)。範囲は両端を含む
  - 取引金額: 最小・最大を数値で入力する (数字のみ)。範囲は両端を含む
  - 取引先: 店名の部分一致キーワード (大文字小文字は無視する)
  - 「検索する」で検索を実行し、「条件をクリア」で全条件と結果を消す
  - 結果は月次一覧と同じ明細行 (`TransactionRow`) で取引日の新しい順に並べ、件数を上に表示する。
    行のタップで明細詳細 (`features/transaction_detail`) を開く
  - 条件未入力なら「検索条件を1つ以上入力してください」、0 件なら「条件に一致する明細はありません」

## フロー

1. 月次一覧の検索アイコンから検索画面を開く
2. 条件を入力し、「検索する」またはキーボードの確定操作で検索する
3. 終了日が開始日より前、最大金額が最小金額未満の場合は検索を実行せず、フォーム下に理由を表示する
4. 結果の明細をタップして明細詳細へ遷移する。詳細で明細を変更・削除すると、検索結果は
   snapshot listener 経由でそのまま更新される

## データ形式

- 明細: `/users/{userID}/transactions/{id}` の `Transaction` (lib/entity/transaction.dart)
- 取引日と金額の範囲は Firestore の where で絞り込む。店名は Firestore が部分一致検索を持たないため、
  取得結果に対してクライアント側で絞り込む (lib/provider/transaction_search.dart)
- 金額の範囲を指定した時のクエリは `amount` 昇順 → `transactionDate` 降順で並べ、複合インデックス
  (firebase/firestore.indexes.json の `amount ASC` + `transactionDate DESC`) を使う。表示順の
  「取引日の新しい順」は取得後にクライアント側で整える
- 検索は「検索する」を押した時点の条件で実行する。入力のたびに Firestore のクエリを張り替えない

## 有効期限・制約

- 条件がすべて未指定の場合はクエリを発行しない (全明細の読み取りになるため)
- 取得件数の上限は設けていない。条件に一致する明細をすべて購読する
- 無料プランでは `features/paywall` の履歴制限 (当月を含む直近 3 ヶ月) を検索にも適用する。
  下限より古い取引日の明細は返さず、ユーザーが指定した開始日がそれより古い場合は下限を優先する
  (lib/provider/transaction_search.dart)。制限中はフォームの下に注記を出し、
  タップでペイウォールを開く。プレミアムになると制限なしで検索し直される
