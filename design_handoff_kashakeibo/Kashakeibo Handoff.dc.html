1. プロダクトとデザイン原則

スクショ・写真を撮ると AI (Gemini vision) が明細を自動作成する家計簿。口座連携をしないことが売りで、明細は必ず元画像と紐づくことが信頼の核。デザイン原則は次の4点。

  • 撮るだけ — 中央のカメラボタンが常に最短経路。取込はカメラ / 写真・スクショ / 手動の3択に集約
  • 元画像にいつでも戻れる — ホームの一等地は「とった記録」(元画像グリッド)。明細詳細でも元画像を大きく表示
  • 褒める・説教しない — 完了トーストで軽く褒める。節約アドバイスや評価コメントは出さない
  • 記録ツールとして誠実 — 数字は等幅・太字で読みやすく。確定申告・経費精算ユーザーも視野 (タグ + CSV書き出し)

2. ビジュアル仕様 (デザインシステム: Organic)

クリーム地 + テラコッタ / セージの2アクセント。角丸強め (16px、ボタン・チップは999px)。アイコンは Lucide、stroke-width 2.75。

タイポグラフィ: アプリ内は Figtree 一本 (和文は Noto Sans JP 等の丸みのないゴシックにフォールバック)。装飾書体 Caprasimo は検討の結果アプリUIでは不採用 (レビューで「鼻につく」)。金額は ExtraBold (w800) + tabular figures、¥記号は一段小さく淡く。見出しは w800、本文 w400–600。最小フォント: 本文13px相当、補助10px相当。タップ領域は44px以上。

3. 画面仕様

画面要点
ホーム「とった記録」元画像サムネイルの3列グリッドが主役 (日付バッジ・金額・店名)。上部に月切替 + 収支1行カード (支出を主、収入/残り/内訳リンクを従)。重複候補バナー、スキャン残量チップ (タップでペイウォール)
取込フローFAB → ボトムシート3択 → カメラ (枠ガイド) → 解析中 (3ステップ表示 + スケルトン) → 確認・修正 (店名/金額/日付/カテゴリ/自動タグ、元画像サムネ常設) → 登録。共有Extensionも確認画面に合流。残量0なら FAB がペイウォールへ
明細詳細金額 → 店名 → 元画像 (拡大可) の順。出所 (自動取込AI / 手動)、タグ、計算対象除外トグル、保存/削除。除外は一覧で45%不透明
重複候補レシート vs カード明細を縦に並べ「金額と日付が一致」を明示。主ボタン=1件にまとめる、副=別々に残す
手動入力金額を最大表示のクイック入力。店名/メモ・カテゴリ・日付 (デフォルト今日)。スキャン残量を消費しない
明細タブ日付グループのリスト。フィルタはインラインではなく「絞り込み」ボタン → ボトムシート (取込元 + タグ、該当件数つき完了)。絞り込み中は状態表示 + クリア
レポート月合計 + カテゴリ横棒 (額降順)。CSV書き出し (元画像つき、確定申告・経費精算向け)。アドバイス文言は置かない
ペイウォール無料枠の使用状況バー (n/10) → 特典3点 → 月額¥480 / 年額¥3,800 (年額を推奨枠 + 「2ヶ月分お得」)。解約可否と復元リンクを明記
設定最上部にバックアップカード (未設定バッジ + Apple/Googleリンク)。プラン、通知、言語、規約/プライバシー、最下部にアカウント削除

4. データ・タグ仕様

  • 明細: id / 日付 / 店名 / カテゴリ (食費・外食・日用品・交通・サブスク・その他) / 出所 (レシート・スクショ・手動) / 金額 / tags[] / 元画像参照 / 除外フラグ
  • 自動タグ: 取込時に付与 — サービス名 (楽天カード、PayPay、Amazon…はスクショのUIから推定)、店種 (コンビニ等)、位置情報 (写真EXIFから地名: 三軒茶屋など)。確認画面で提示、詳細で表示、明細タブの絞り込みに使用
  • 重複検知: 金額 + 日付 (±数日) の一致でレシート×カード明細の候補を提示。マージ時は元画像を両方保持

5. モーション・音 (「カシャ」体験)

  • シャッター: 白フラッシュ約120ms + シャッター音 + 軽ハプティクス。押下時にボタン scale 0.96 (日本のiOSはシャッター音消音不可仕様に準拠)
  • 解析中: 3ステップ (読み込み → 金額・日付 → カテゴリ) + スケルトン。2秒未満なら中間スキップ。失敗時は手動入力へ誘導
  • 登録完了: セージのトースト (褒め文言を数種ローテーション) + グリッド先頭に新サムネイルがスライドイン
  • 画面遷移・シートは 200–250ms ease-out。過剰な演出はカシャ周りに限定する

6. 多言語・その他の制約

  • 試作は日英併記だが、実装は locale 切替 (日本語 / 英語)。英語で1.5倍程度伸びても壊れないよう、行レイアウトは Flex + gap、金額は右寄せ固定、ラベルは折返し許容
  • 「レシート画像」に限定しない語彙: 元画像 / source image (カード明細・入出金画面のスクショも対象)
  • ダークモード対応前提 — トーンランプ (100–900) の反転利用で設計。別途配色確認が必要 (未着手)

7. 経緯と未決事項

  • 方向決定: 3案比較 → 1a「きちんと整う」を採用、数字書体を 2a (ExtraBold + tnum) に修正。キャラ案 (1b カシャちゃん) は不採用だが、褒めトーストに軽さとして残存
  • 未決: ダークモード配色 / 英語のみ表示の検証 / CSV書き出しのカラム定義 / タグの編集UI (手動追加・削除) / オンボーディングと共有Extensionの説明画面 / 実画像でのグリッド見え方
